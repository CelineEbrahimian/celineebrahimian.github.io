# Celine Ebrahimian — Engineering Portfolio

Personal portfolio site, hosted on GitHub Pages.

- `index.html` — the whole site (content, styles, image viewer)
- `images/` — project photos

## Editing
- **Project video:** search `index.html` for `PASTE_YOUTUBE_LINK_HERE` and replace it with your YouTube URL.
- **Add photos:** drop a `.jpg` into `images/` and copy any `<figure>…</figure>` line in a project's `gallery` block, changing the file name and caption.
- **Text:** every project has a `What`, `How`, and `Lessons`/`Impact` block. Edit the text between the tags.
